# Customer Shopping Behavior Analysis

##Retail customer shopping behavior analysis using PostgreSQL and SQL

## Project Overview

This project focuses on analyzing retail customer shopping behavior using **PostgreSQL and SQL**. The objective is to explore customer purchasing patterns, product performance, sales trends, and return behavior to generate meaningful business insights.

The project uses a retail shopping dataset containing transaction-level information, including customer demographics, product categories, purchase amounts, discounts, payment methods, and delivery details.

## Objectives

- Analyze overall sales and revenue performance.
- Understand customer purchasing behavior.
- Identify top-performing products and brands.
- Evaluate category-wise sales performance.
- Analyze customer purchase frequency and spending patterns.
- Investigate product returns and customer feedback.
- Generate insights that can support business decisions.

## Dataset Description

The dataset contains retail transaction records with fields covering:

- **Customer Information:** Customer ID, age, gender, location.
- **Product Information:** Category, item purchased, brand, size, color.
- **Transaction Details:** Transaction ID, purchase date, quantity, purchase amount.
- **Purchase Behavior:** Subscription status, previous purchases, purchase frequency.
- **Order Information:** Online/offline channel, payment method, shipping charge, delivery speed and delivery days.
- **Customer Feedback:** Review rating and return status.
